# Create 1-Pager

Create a decision-focused 1-Pager in narrative document format.

## When to use

- When you need leadership buy-in for an initiative
- To verify whether an Outcome and Opportunity are worth pursuing
- Before committing resources to a new project

## Core purpose

Verify whether the Outcome and Opportunity are truly valuable enough to be addressed as initiatives or projects. The question: "Are this opportunity and goal important enough?"

## Process

1. **Clarifying questions**: Collect information about Outcome, Opportunity, Lessons, Solutions, Assumptions, and Decision Request
2. **Narrative writing**: Write each section as a storytelling paragraph
3. **Bullet summary**: After each paragraph, organize 2-4 key points as bullets
4. **Risk framework**: Examine assumptions using four axes: Value, Viability, Feasibility, Usability Risk
5. **Decision triggers**: End with clear decision points for leadership discussion

## Sections

Outcome -> Opportunity -> Lessons -> Solutions & Assumptions -> Decision Requests

## Output

- **Format:** Markdown (`.md`)
- **Location:** `2-definition/2.1-prd/` (legacy: `definition/prd/`)
- **Filename:** `1-pager-[initiative-name].md`

## Rules

- Do not generate immediately; always collect input through clarifying questions first
- Write in narrative + summary bullet structure
- Verify the completed document triggers discussion, reveals uncomfortable facts, and enables decision resolution
