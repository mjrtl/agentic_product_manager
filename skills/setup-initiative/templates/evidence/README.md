# Evidence and supporting material

Put supporting material for discovery here — documents that back up the ODD and help stakeholders align quickly.

Examples:

- Problem statement
- Risk analysis
- Discovery plan
- Business case / ROI notes
- Stakeholder notes
- Screenshots / exports (if needed)

Rule of thumb:

- If it is **core narrative** → it belongs in `0-intake-and-scoping/0.1-odd/opportunity-discovery-doc.md` (legacy: `discovery/opportunity-discovery-doc.md`).
- If it is **supporting detail** → it belongs here.
