# Implementation Tasks

This folder contains the detailed task breakdown for implementing this initiative.

## Files to Create

### [initiative-name]-tasks.md

Main implementation task list.

**Usage:** Use the task-management skill's "generate tasks" workflow to create tasks from your PRD.

**Processing:** Use the task-management skill's "process task list" workflow to work through tasks systematically.

### task-progress.md

Track overall progress and completed tasks.

**Structure:**
```markdown
# Task Progress

## Sprint/Week [X]
**Completed:**
- [Task 1.1]: [Brief description]

**In Progress:**
- [Task 2.1]: [Current status]

**Blocked:**
- [Task 3.1]: [Blocker description]

**Next Week:**
- [Task 4.1]: [Planned]
```

## Task Management Process

### 1. Task Generation
- Use PRD as input for task generation
- Break down into small, manageable tasks
- Estimate effort and dependencies

### 2. Task Processing
- Work on one task at a time
- Review and approve before moving to next

### 3. Progress Tracking
- Update task status regularly
- Document blockers and solutions
- Communicate progress to stakeholders

---
*Use the systematic task processing approach for reliable execution.*
