# User Story Map & Epics

Top-level user stories and epics for this initiative. Required for **Definition of Ready** before handoff to delivery.

## Purpose

- Part of Keyrock’s definition phase: User Story Map (Activities → Tasks → Stories → Release slices) and Epics aligned to ODD and OKRs.
- Repo is the process home; Notion/Miro often hold the live USM. This folder can contain:
  - A summary or epic list in markdown, or
  - A link to the Notion page or Miro board where the USM lives.

## What to put here

- **Option A:** `user-story-map.md` (or similar) with Activities, Tasks, and Stories; epic list with naming `[Feature Area] - [User Outcome]`.
- **Option B:** `notion-or-miro-link.md` with the URL and a one-line description so the agent and PM know where the canonical USM is.

## Definition of Ready

Before running `/generate-tasks`, this folder must have content (summary or link). Run `/check-dor <initiative-name>` to verify.

## Keyrock alignment

- User Story Map Template: Activities → Tasks → User Stories → Release slices.
- Epic naming: `[Feature Area] - [User Outcome]`.
- Link back to ODD (`0-intake-and-scoping/0.1-odd/opportunity-discovery-doc.md`) and OKRs.
