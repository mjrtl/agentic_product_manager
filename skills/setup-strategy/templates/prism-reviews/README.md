# PRISM reviews

PRISM strategy review outputs for this strategy area.

## File naming

- Review outputs: `prism-review-[YYYY-MM-DD].md`
- Review data: `prism-review-[YYYY-MM-DD].json`

## How to use

1. Prepare your strategy document and supporting evidence
2. Run `/prism-review` to score across 5 PRISM dimensions
3. Save both `.md` and `.json` outputs here
4. Track scores over time in the review log

## PRISM dimensions (scored 0-5)

- **P** - Problem diagnosis
- **R** - Reframe opportunity
- **I** - Intentional bets
- **S** - Systemized execution
- **M** - Momentum and meta-reflection

## Decision thresholds

- Score < 2.5: Revise and resubmit
- Score 2.5-3.4: Provisionally approved with improvements
- Score >= 3.5: Approved
