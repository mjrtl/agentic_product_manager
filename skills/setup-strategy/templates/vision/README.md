# Vision

Vision documents and review outputs for this strategy area.

## File naming

- Vision reviews: `vision-review-[YYYY-MM-DD].md`
- Vision drafts: `vision-[strategy-name]-v[N].md`

## How to use

1. Draft or paste your product vision document into this folder
2. Run `/vision-review` to score it against 4 criteria
3. Save the review output here with the date-based naming convention
4. Iterate on the vision based on review feedback

## Vision criteria (scored 0-5)

1. Lofty and inspiring
2. Realistic and attainable
3. Constraint-free
4. Grounded in user problem
