# Team structure

Org design analyses and team structure decisions for this strategy area.

## File naming

- Team structure analyses: `team-structure-[YYYY-MM-DD].md`
- Org design proposals: `org-design-[topic]-v[N].md`

## How to use

1. Gather current org charts, role definitions, and team missions
2. Run `/team-structure` to analyze against 4 organization models
3. Save analysis outputs here
4. Document restructuring decisions and rationale

## Organization models evaluated

1. Functional
2. Matrix
3. Value stream
4. Divisional

## Key question

Does the current team structure enable the strategic bets defined in the PRISM review?
