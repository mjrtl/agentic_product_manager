# OKRs

OKR drafts and finalized OKRs organized by period.

## File naming

- OKR documents: `okrs-[period]-v[N].md` (e.g., `okrs-2025-q2-v1.md`)
- Period format: `YYYY-QN` for quarterly, `YYYY-HN` for half-yearly

## How to use

1. Draft your OKRs for the upcoming period
2. Run `/okr-coach` to get structured feedback
3. Save revised versions with incremented version numbers
4. Link finalized OKRs to initiatives

## OKR quality checklist

- [ ] Objectives are inspiring and strategic (not task lists)
- [ ] Key results are outcomes, not outputs
- [ ] Each objective has 2-4 key results
- [ ] Key results are measurable with clear targets
- [ ] Causal relationships between KRs and objectives are valid

---
*Use `/okr-coach` for OKR sparring and structured criticism.*
